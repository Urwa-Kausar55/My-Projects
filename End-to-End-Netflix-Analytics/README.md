# Netflix Content Intelligence Dashboard

![Dashboard Preview](https://github.com/Urwa-Kausar55/My-Projects/blob/main/End-to-End-Netflix-Analytics/Netflix-Dashboard-Preview.png)

## Project Overview
This project focuses on analyzing Netflix's content library to extract key insights regarding trends and subscriber preferences.

* **Tools Used**: Power BI, Python (Pandas, NumPy).
* **Key Tasks**: Data Cleaning, Exploratory Data Analysis (EDA), and Dashboard Visualization.

  ## 📖 Project Overview
This project provides a comprehensive end-to-end data analysis of the Netflix content library. The objective is to identify key trends in global content production, audience preferences, and platform strategy. This project showcases my proficiency in data wrangling, and visual storytelling.

## 🚀 Technical Workflow
I followed a structured data Analytics pipeline to ensure accuracy and clarity:

* **Data Wrangling (Python):** 
    - Used **Pandas** and **NumPy** for data cleaning, including handling missing values, standardizing date formats, and filtering relevant subsets.
    - Conducted Exploratory Data Analysis to uncover underlying patterns in the dataset.
* **Data Visualization (Power BI):** 
    - Designed an interactive, user-friendly dashboard.
    - Implemented advanced slicers and calculated measures to allow dynamic filtering by release year and region.
    - Visualized complex relationships, such as the growth of Movies vs. TV Shows over time.

## 📊 Key Analytical Insights
Through this analysis, I identified several critical insights:
- **Global Production Patterns:** Highlighting which countries are leading in content creation.
- **Content Evolution:** Visualizing how the balance between Movies and TV Shows has shifted over the last decade.
- **Genre Popularity:** Pinpointing the most dominant content categories on the platform.

## 🛠️ Tools & Technologies
* **Programming:** Python (Pandas, NumPy)
* **Visualization:** Power BI (Desktop)
* **Methodology:** Data Cleaning -> Exploratory Data Analysis (EDA) -> Interactive Visualization
